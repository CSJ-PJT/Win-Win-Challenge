# 안심동행 플랫폼 · 심사 시연 안내

차량의 도착과 사람의 인수 확인을 분리해, 보호자와 시설이 같은 방문의 진행 상황을 확인하는 앱입니다.

## 빠르게 체험하기

**Android 시연 APK:** [안심동행플랫폼 release](../apk/안심동행_안심동행플랫폼_release.apk)

**PC 시연:** Node.js 22 이상 환경에서 저장소를 내려받아 아래 명령으로 실행합니다.

```bash
npm run bundle
node tools/serve-demo.cjs
```

브라우저에서 `http://127.0.0.1:18420/`을 열면 역할 선택 화면 없이 시연이 시작됩니다. HTML 파일을 직접 더블클릭하면 공식 주소 검색 결과를 돌려받을 수 없으므로 PC 실행.cmd 또는 위 서버 실행 방식을 사용해 주세요.

## 주요 시연 흐름

1. **인계자** 탭에서 ‘도착지 입력하기’를 선택합니다. 주소 검색에서 도로명 주소를 선택하거나 주소를 직접 입력한 뒤 ‘도착지 저장’을 누릅니다. 주소가 저장된 화면에서 지도 연결과 방문 시작을 확인할 수 있습니다.
2. ‘방문 시작하기’ → ‘도착했어요’ → ‘연결번호 받기’ → ‘직접 인계했어요’를 진행합니다. 이때 인계자 확인만 완료되고 인수는 아직 대기 상태입니다.
3. 상단 **시설** 탭에서 ‘맞이할 준비 완료’를 선택하고, 인계자가 받은 6자리 번호를 입력해 ‘직접 인수했어요’를 누릅니다.
4. 상단 **보호자** 탭에서 양측 확인 완료와 시각을 조회합니다.
5. 상단 **쉬운 화면** 탭에서 주야간보호센터 방문을 선택한 뒤, ‘동의하고 계속’ → ‘도착 알리기’를 진행합니다. 시설 탭에서 도착 알림을 확인하면 쉬운 화면에도 확인 상태가 표시됩니다.

상단 역할 탭을 바꿔도 같은 방문 기록을 유지합니다. 보호자 조회 화면은 상태를 표시하고, 시설 화면은 인수 처리에 필요한 정보만 표시합니다.
