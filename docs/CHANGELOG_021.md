# 0.2.1 · 시연 동선 수정

첫 실행과 새 방문에서는 출발 가능한 차량·담당자 상태를 준비한다. 도메인의 기본 상태와 실제 AAOS 주행 제한은 바꾸지 않는다.

차량 화면에서 출발, 도착·정차, 연결번호 발급, 인계 확인을 순서대로 진행한다. 인계자 확인 후 시설 화면으로 이동하고, 연결번호를 불러온 뒤 별도로 인수 확인한다. 두 확인을 자동 승인하지 않는다.

차량·시설·보호자 전환, 방문 변경, 다시 시작을 주 화면에 배치했다. 어르신 화면에서는 도착 알림과 담당자 확인까지 진행할 수 있다. 연락처가 없으면 전화 화면에서 번호를 입력한다.

반복적인 가상 방문·전송 여부 설명과 기록 문장의 군더더기를 삭제했다. 장애·번호 불일치·동의 확인 등 실제 행동에 필요한 안내는 남겼다.

단일 HTML은 로컬 웹 서버로 열어도 백엔드 API를 찾지 않는다. 알림 팝업이 버튼 터치를 가로채지 않도록 수정했다. 작은 화면에서는 다음 동작을 장소 정보보다 먼저 배치했다.

웹 테스트와 Android APK 검증 결과는 build-reports/v021 및 Actions 산출물에 기록한다. 전화는 사용자가 입력한 번호로 전화 앱만 연다. 자동 발신, 실기관 메시지 전송, 실차 제어는 추가하지 않았다.
