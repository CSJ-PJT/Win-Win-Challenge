# 안심동행 플랫폼 v0.4.0 — 검증 범위

## 주요 변경

- 방문 정보 입력 중 서버 폴링·차량 신호 갱신이 입력창을 제거하지 않도록 편집 화면을 분리했다.
- 방문자/보호자 연락처, 시설/담당자, 방문 일시, 승하차 장소, 도착지 주소, 글씨 크기, 지도 선택을 저장한다.
- 도착지가 없으면 간단한 주소 입력 화면을 열고, 주소 저장 후 별도의 길안내 버튼을 제공한다.
- Google Maps URLs의 길안내는 API 키 없이 주소로 동작한다. 카카오맵은 좌표가 있는 경우 길찾기 URL을 사용한다. Android는 기기 Geocoder를 통한 주소 검색을 지원하고, 실패 시 직접 입력과 외부 지도 검색을 유지한다.
- 보호자·인계자, 읽기 전용 보호자, 시설 인수 담당자, 큰 글씨 사용자 화면을 분리한다. 인계는 양측의 확인을 요구한다.

## 검사

- `npm test`: 도메인/서버 API/설정/지도 링크 등 자동 검사
- `python3 test/flow040.py`: 일반·시설·보호자·어르신 전체 과정 및 입력 12초 유지
- `python3 test/ui040_regression.py`: 주소 입력·검색 실패·좌표 결과·지도 전환·200% 큰 글씨 등
- `python3 test/flow040_http.py`: 실제 로컬 HTTP 서버에서 별도 역할 창 간 상태 공유 (CI)
- `python3 test/android_smoke.py <apk>`: Android 에뮬레이터 키보드, 화면, 지도 인텐트, 양측 인계, 쉬운 화면 (CI)

## 설치 시 외부 시스템 연결

Google Maps URLs는 키가 필요하지 않지만 단말기에 지도/브라우저 앱과 인터넷이 있어야 경로를 볼 수 있다. 앱 내 장소 검색은 Android 기기의 Geocoder 또는 `KAKAO_REST_API_KEY`를 설정한 로컬 서버에서 지원한다. 키가 없으면 외부 지도 검색과 직접 주소 입력을 사용한다. 검색 결과 정확도, 지도 화면의 경로 선택 및 자동차 사용 가능 여부는 해당 제공자에 따른다.

APK는 로컬에 단일 방문 기록을 저장하는 시연판이다. 기관별 계정 인증, 여러 APK 간 클라우드 동기화, 실제 시설의 공식 승인, Pleos 실차 SDK 연동은 개발 및 별도 검증 범위다. 시연 화면의 역할 변경은 운영 권한 제어가 아니다.
