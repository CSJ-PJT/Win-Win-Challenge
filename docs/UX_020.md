# 0.2.0 화면과 검증 범위

## 화면 원칙

일반 화면은 역할별 다음 행동을 보여준다. 쉬운 화면은 도착 소식과 전화만 제공한다. 글씨와 버튼을 크게 하되, 나이만으로 쉬운 화면을 강제하지 않는다. 설정에서 기본 화면으로 돌아갈 수 있다.

도착 소식은 본인이 누른 기록이다. 차량 위치나 정차를 측정한 결과가 아니며 인계 확인과 별도로 저장한다. 담당자 읽음 표시는 도착 소식을 읽었다는 뜻으로만 사용한다.

## 이번 구현

- 쉬운 화면의 주요 글씨 22 CSS px 이상, 주요 버튼 높이 72px 이상.
- 200% 글씨 확대와 작은 화면에서 세로 흐름 유지.
- 수신자 확인 후 도착 소식 전송, 담당자 읽음 표시.
- 전송 실패·응답 유실 구분, 같은 요청 식별자로 재확인.
- 일반 화면의 연결번호 입력은 시설 화면에만 표시.
- 모달 초점 이동·초점 가두기·Escape, Android 뒤로 가기.
- Android 시스템 글씨 배율 반영, 전화 앱 열기. 자동 발신 없음.
- 설정과 로컬 체험 상태 저장. 기존 서버 상태는 visitor 역할을 추가해 보존.

## 아직 별도 확인할 항목

Android 실기기의 TalkBack 탐색, OEM별 글자 확대, Pleos 에뮬레이터와 실차 연동, 실제 시설 사용자 시험. 이번 브라우저·도메인 시험 결과로 이 항목들을 대신하지 않는다.
