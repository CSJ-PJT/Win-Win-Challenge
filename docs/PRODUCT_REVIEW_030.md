# 안심동행 플랫폼 0.3.0

## 이용 구조

시설이 방문을 준비하고, 보호자·인계자가 이동과 직접 인계를 진행하는 구조다. 시설 담당자는 자기 시설의 방문 대상, 인수 준비, 대면 인수 확인과 연락처를 사용한다. 보호자는 방문 전체 진행 상황을 조회하고, 인계자는 자신의 직접 인계만 확인한다. 어르신용 쉬운 화면은 도착 알림과 전화에 집중한다.

현재 ‘인계자 대면 확인 — 대기 중’은 조회 상태다. 인계자가 정차·연결번호 발급 후 ‘직접 인계했어요’를 누르면 바뀐다. 시설 담당자가 이를 대신 완료할 수 없다. 두 사람이 각각 확인한 경우에만 인계가 완료된다.

## 이번 변경

- 사용 유형 선택을 처음 한 번 받고 저장한다. 일반 화면에서는 다른 역할로 넘어가는 탭을 없앴다. 역할별 시연은 하단 시연 도구에서 전환한다.
- 시설은 방문자 맞이·준비·인수 확인을 제공하고, 전체 운행 과정과 운전자 조작은 제외했다.
- 이용자, 인계자, 보호자 연락처, 시설·담당자, 승하차 장소, 방문 일시, 이동 도움 요청을 설정으로 옮겼다.
- 도착지 주소와 좌표를 저장한다. 출발 시 도착지가 없으면 주소 설정으로 연결한다. 다음 방문에는 저장한 내용을 재사용한다.
- 방문 시작 또는 도착 소식 접수 후에는 방문 대상·주소를 바꿀 수 없다. 새 방문에서 변경한다. 확인 상태·계정 권한·담당자 ID는 설정 항목이 아니다.
- 담당자나 시설을 바꾸면 기존 준비 확인을 취소한다. 어르신 방문 대상이 바뀌면 본인 동의를 다시 받는다.

## 지도 연결

Android 앱의 ‘주소 찾기’는 Android Geocoder를 호출한다. 결과를 선택하면 주소·좌표가 저장된다. 검색 서비스가 없거나 연결이 실패하면 직접 주소 입력과 지도 검색을 제공한다. 검색하지 못한 주소의 좌표를 만들어 넣지 않는다.

카카오맵과 Google 지도 중 선택할 수 있다. 좌표가 있으면 목적지를 전달한다. 카카오맵에서 좌표 없이 주소만 있는 경우에는 해당 주소의 지도 검색으로 연결하며, 검색 결과에서 길찾기를 선택한다. 앱 안에서 지도를 직접 렌더링하거나 턴바이턴 내비게이션을 구현한 것은 아니다. 지도에는 장소·주소·좌표만 보내고 이용자 이름이나 연락처를 보내지 않는다.

웹 서버의 장소 검색은 KAKAO_REST_API_KEY 환경변수로 Kakao Local API를 연결할 수 있다. 키는 서버에만 두고 APK와 HTML에 포함하지 않는다. 키 미설정 시에도 외부 지도 검색은 사용할 수 있다.

공식 개발 문서:
- https://developer.android.com/reference/android/location/Geocoder
- https://apis.map.kakao.com/web/guide/#roadmapurl
- https://developers.google.com/maps/documentation/urls/get-started
- https://developers.kakao.com/docs/ko/local/dev-guide

## 사업 운영 판단

첫 유료 고객 후보는 기관이고, 보호자·이용자는 방문 과정의 사용자다. 시설 담당자의 업무를 줄이지 못하면 도입 이유가 약해진다. 기관 도입 검증에서는 준비 확인에 드는 시간, 인수 대기 건수, 연락 재확인 횟수를 측정한다. 과금은 실제 기관 인터뷰와 사용 시험 후 정한다.

현재 배포는 단일 방문 데이터로 이용 과정을 확인하는 비공개 시연 버전이다. 역할 선택은 기관 계정 인증이 아니며 로컬 시연 서버의 bootstrap은 시험 역할 토큰을 제공한다. 실제 기관 운영 전에 기관별 계정·초대, 서버 측 기관/대상별 접근제어, 담당자 승인, 다중 방문 목록, 동의·삭제 정책, 운영 알림 채널과 감사를 별도로 구현해야 한다. 현재 로컬 서버는 loopback 바인딩과 Host/Origin 검사로 외부 공개를 차단한다.

따라서 이번 배포 범위는 APK·HTML 체험과 로컬 서버 검증이다. 앱스토어 등록, 공개 서버, 실차 및 실제 시설 연계 완료를 뜻하지 않는다.
