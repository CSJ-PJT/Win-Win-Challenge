# 심사 시연 진행안

합성 시설·이용자·차량 신호를 사용하는 로컬 PoC입니다. 운영 로그인 계정은 사용하지 않습니다. 제품8f4aaf9/0.4.3, 지정APK09e488aa와 CI40887985855가 기준입니다.

1. `npm start` 후 /vehicle·/facility·/guardian를 엽니다. 공개장소 주소를 저장합니다. 여러 역할 화면이 같은 로컬 서버 상태를 조회합니다.
2. 인계자에서 방문 시작하기 → 도착했어요 → 연결번호 받기를 누릅니다. 시연 초기 정차·시설 준비는 모의 조건입니다.
3. 직접 인계했어요를 누릅니다. 아직 완료가 아니며 시설 확인을 기다립니다.
4. 시설에서 번호를 입력하고 직접 인수했어요를 누릅니다. 보호자 화면에서 양측 확인·완료 시각을 봅니다. 이는 화면 상태 공유이며 실제 폰 push는 미검증입니다.
5. 새로고침·같은 DATA_FILE로 서버 재시작 후 저장된 주소와 완료 상태를 확인합니다.
6. 방문 변경에서 주야간보호센터 새 방문 → 쉬운 화면 → 동의하고 계속 → 도착 알리기. 시설의 도착 알림 확인 뒤 쉬운 화면 재진입에서 담당자 확인 상태가 유지되는지 봅니다. 자기 신고 도착 소식은 대면 인계 완료와 별도입니다.

자동 재현은 `node tools/poc-e2e.cjs`입니다. 실제 HTTP 서비스·파일 복원 검증이며 화면 클릭 자동시험과 구분합니다. 상세 화면ID·권한·오류·기존 UI 검증 근거는 [PoC 검토 안내](POC_REVIEW_GUIDE.md)를 봅니다.

틀린 번호·담당자 미준비·연결 실패를 완료로 표시하지 않습니다. 실제 전화 발신·기관 알림·차량 경로안내를 시연하지 않습니다. 일반 Android 녹화를 Pleos 실제 차량 검증으로 부르지 않습니다.
