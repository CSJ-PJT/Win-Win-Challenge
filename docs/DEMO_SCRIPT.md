# 심사 시연 진행안

처음에 가상 시설·이용자·모의 차량 신호임을 밝힙니다. 왼쪽은 차량, 가운데는 시설, 오른쪽은 보호자입니다.

## 도착과 인계

시설 준비와 차량 정차를 입력하고 출발·도착을 모의합니다. “차는 도착했지만 담당자가 인수했는지는 아직 확인되지 않았습니다.”

## 양측 직접 확인

차량에서 번호를 발급하고 인계자 직접 확인을 기록합니다. 시설에 번호를 입력하고 인수자 직접 확인을 기록합니다. “번호는 두 화면을 같은 이동 건에 연결합니다. 번호를 아는 사람을 인수자로 인정하지 않습니다. 지정된 두 역할의 확인이 모두 있어야 완료됩니다.”

## 예외 처리

새 시연에서 담당자 부재와 통신 끊김을 시험합니다. “완료 여부를 추정하지 않습니다. 연결이 복구돼도 미확인 인계를 자동 완료하지 않습니다. 현장 인계 절차가 앱보다 우선입니다.”

## 성인 이용자 선택

경로당 자율 방문을 선택하고 본인 동의 후 도착만 알립니다. “지정 담당자가 없는 자율 방문에는 인계 완료라는 표현을 쓰지 않습니다.”

실제 NaviHelper 어댑터는 별도의 연결 확인·공식 예제 경로 시험입니다. 일반 Android 녹화를 Pleos 시연이라고 부르지 않습니다. AAOS 제한 차단은 차량 환경에서 따로 검증해야 합니다. 로컬 가상 역할 토큰은 운영 인증체계가 아닙니다.
