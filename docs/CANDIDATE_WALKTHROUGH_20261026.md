## 1. 공식 주소 선택·저장
인계자 → 필요하면 방문 변경에서 유치원 등원 → 도착지 입력하기(기존 주소가 있으면 도착지 변경).
주소 입력에 공개 장소 `세종대로 110` → 주소 검색 → 공식 결과 `서울 중구 세종대로 110` 선택 → 우편번호 `04524`와 반환 주소 확인 → 도착지 저장.
키보드가 가리면 닫고 저장 버튼까지 스크롤합니다. 메인 주소와 방문 시작하기가 보여야 저장 단계 완료입니다.
정보 편집은 출발 준비 단계에서 수행합니다. 진행 중인 방문에서는 화면 설정만 저장될 수 있으므로 새 방문 여부를 먼저 확인합니다.

## 2. 주요 버튼으로 양측 인계
| 순서 | 화면·입력 | 확인할 결과 |
|---|---|---|
| 1 | 인계자, 저장한 도착지 → 방문 시작하기 → 도착했어요 | 대면 인계 단계 |
| 2 | 시설 → 맞이할 준비 완료가 보이면 선택 | 맞이할 준비가 됐어요 |
| 3 | 인계자 → 연결번호 받기 | 현재 화면의 6자리 숫자·남은 시간 |
| 4 | 인계자 → 직접 인계했어요 | 인계자 확인 표시, 시설 확인 대기 |
| 5 | 시설 → 현재 화면에서 읽은 6자리 숫자 입력 → 직접 인수했어요 | 인수를 완료했어요 / 양쪽 확인 완료 |
| 6 | 보호자 탭 | 인계를 마쳤어요, 양측 확인됨 |

동의가 필요한 방문은 본인 동의를 먼저 확인합니다. 안내의 고정 예시 숫자를 연결번호로 쓰지 않습니다. 시연 도구의 번호 자동 채우기를 쓰지 않고 화면 번호를 직접 옮깁니다.
주소·번호 외에 실제 개인정보/전화번호는 이 검토를 위해 추가 입력할 필요가 없습니다. 기본 합성 방문을 사용합니다.
준비 상태는 10분, 연결번호는 2분 유효합니다. 새 번호를 받으면 양측 확인을 다시 해야 합니다.
근거: DomFlowTest의 수동주소 DOM 흐름과 android_smoke.py의 실제 UI 흐름은 별개. CI APK UI7, DOM JUnit1·16.075초, PRIMARY_HANDOFF_OK 및 EASY_ARRIVAL_ACK_OK.

## 3. 큰 버튼 도착 알림
쉬운 화면 → 주야간보호센터(또는 경로당) → 동의하고 계속 → 도착 알리기.
‘도착 소식을 남겼어요 / 담당자가 확인하면 알려드려요’는 알림 등록 후 대기 상태입니다.
시설 → 도착 알림 확인 → 쉬운 화면으로 돌아가 ‘담당자가 확인했어요’를 확인합니다. 도착 알림 ACK를 양측 대면 인계 완료로 합산하지 않습니다.
다른 방문 시작하기는 새 방문을 시작하므로 검토 대상 상태를 기록한 뒤 사용합니다.
