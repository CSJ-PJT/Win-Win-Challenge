## 수정 이력에서 구분할 점

첫 빌드에서는 SDK 문서의 Java RouteInfo 예제와 배포 라이브러리 생성자 차이로 컴파일 오류가 발생했습니다. Kotlin 이름 기반 인자와 SDK 기본값을 사용하도록 수정했습니다. 그다음 설치 시험에서는 프로세스는 살아 있었지만 웹 화면이 로딩 상태에 머물렀습니다. Android 자산을 단일 HTML로 번들링하고, 화면·버튼 존재 검사 및 JavaScript 오류 기록을 추가한 빌드에서 실제 화면을 확인했습니다. 설치·프로세스 생존만으로 성공이라 판단하지 않습니다.
