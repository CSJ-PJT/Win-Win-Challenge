# 안심동행 플랫폼

차량 도착과 사람의 인계 확인을 연결합니다.

## 0.2.1 — 바로 진행하는 시연

앱을 열면 출발 버튼부터 사용할 수 있습니다. 차량·시설·보호자 탭과 방문 변경을 주 화면에 배치했습니다.

### 기본 화면

**이 목적지로 출발하기 → 도착·정차하기 → 연결번호 받기 → 직접 인계했어요 → 시설 화면에서 확인하기 → 번호 불러오기 → 직접 인수했어요**

완료 후 보호자 화면에서 결과를 확인하거나, **다시 시작하기**로 새 방문을 열 수 있습니다. 연결번호는 직접 입력해도 됩니다. 차량과 시설의 확인은 각각 눌러야 합니다.

### 큰 글씨·쉬운 화면

**돌봄센터 방문 → 동의하고 계속 → 도착 알리기 → 도착 소식 보내기**

결과 화면의 **담당자 화면 보기**에서 도착 소식을 확인하면 읽음 상태가 반영됩니다. 경로당 방문도 선택할 수 있습니다. 도착 소식과 대면 인계는 별도의 기록입니다.

**담당자에게 전화**에서 연락처를 입력하고 전화 앱을 열 수 있습니다. 전화번호는 사용자가 등록하며 자동 발신하지 않습니다.

## 실행

- Android: `apk/ansim-platform-0.2.1-preview.apk`
- 설치 없는 화면: `dist/handoff-demo.html`
- 여러 브라우저 창 연결: 아래 명령으로 로컬 서버 실행

```sh
npm test
npm run bundle
npm start
```

Node.js 22 이상이 필요합니다. `http://127.0.0.1:8080`에서 열며 `/vehicle`, `/facility`, `/guardian`, `/visitor`는 역할별 진입 경로입니다.

단일 HTML은 파일로 열거나 정적 웹 서버로 열어도 별도 API 없이 동작합니다. APK는 이 단일 화면을 포함합니다. 로컬 서버와 APK의 자동 연결은 지원하지 않습니다.

이번 0.2.1 APK의 시험용 서명 키는 이전 버전과 다릅니다. 업데이트 설치가 거부되면 이전 앱을 삭제한 뒤 설치해야 하며, 삭제 시 기기의 이전 시연 기록은 지워집니다.

## 변경 내용

- 첫 방문의 정차·담당자 준비 상태를 시연 화면에서 준비합니다. 도메인 기본값과 실제 AAOS 주행 제한은 유지합니다.
- 출발부터 인계 완료까지 필요한 다음 버튼을 주 화면에 표시합니다.
- 반복적인 가상 방문·전송 여부 설명을 제거했습니다.
- 입력하지 않은 연결번호에는 직접 안내를 표시하고 해당 칸으로 이동합니다.
- 통신 장애, 차량 상태 미확인, 담당자 부재 등은 별도 시연 도구에서 시험합니다.
- 작은 화면에서는 다음 행동을 장소 정보보다 먼저 보여줍니다.
- 알림 메시지가 버튼 터치를 가로채지 않도록 수정했습니다.

## 검증

```sh
npm test
python3 -m pip install playwright==1.57.0
python3 test/browser_smoke.py
python3 test/demo_flow.py
```

단위·HTTP 테스트 81개, 실제 HTTP 브라우저 검사 28개를 통과했습니다. 결과와 화면은 `build-reports/v021/`에 있습니다.

CI는 서명된 release APK를 빌드한 후 Android 15 에뮬레이터에서 출발·인계·쉬운 화면을 직접 조작합니다. 네이티브 실행 결과는 해당 Actions 실행의 `ansim-platform-0.2.1-native-check` 산출물에 보관합니다. Pleos 및 실차 검증과는 구분합니다.

서버는 루프백 주소에서 합성 데이터와 시연용 역할 토큰을 사용합니다. 접수용 개인정보, 인증키와 로컬 상태 파일은 저장소에 포함하지 않습니다.
