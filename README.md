# 안심동행 플랫폼

차량 도착과 사람의 인계 확인을 연결하는 공모전용 프로토타입입니다.

## 0.2.0 — 쉬운 화면

큰 글씨의 `도착 알리기`와 `담당자에게 전화`를 중심으로 화면을 다시 구성했습니다. 차량·시설·보호자 화면은 각 역할의 다음 동작만 보여줍니다. 역할 변경, 가상 차량 신호와 장애 시험은 **시연 도구**에서 선택합니다.

- 쉬운 화면: 본인 동의 → 수신자 확인 → 도착 소식 → 담당자 읽음 확인.
- 도착 소식은 인계 상태와 별도입니다. 소식을 보내거나 읽어도 인계 완료가 되지 않습니다.
- 일반 화면: 차량과 지정 담당자의 대면 확인이 모두 있어야 완료됩니다.
- 화면 방식과 글씨 크기(100/125/150/200%)를 저장합니다.
- 통신 장애 때 완료로 표시하지 않습니다. 응답을 놓친 요청은 같은 요청 ID로 결과를 확인합니다.
- 전화 버튼은 시스템 전화 앱을 엽니다. 자동으로 발신하지 않습니다. 예시 전화번호를 임의로 넣지 않았습니다.

## 실행

Node.js 22 이상에서 외부 npm 패키지 없이 실행합니다.

```sh
npm test
npm run bundle
npm start
```

브라우저에서 `http://127.0.0.1:8080`에 접속합니다. 차량, 시설, 보호자, 쉬운 화면은 각각 `/vehicle`, `/facility`, `/guardian`, `/visitor`로 열 수 있습니다. 같은 서버의 여러 창이 상태를 공유합니다.

설치 없는 단일 기기 체험은 `dist/handoff-demo.html`입니다. **쉬운 화면 → 쉬운 화면 체험 시작 → 동의하고 계속** 순서로 체험할 수 있습니다.

## Android

`android/`는 기존 Pleos NaviHelper 연동 코드를 포함한 Android 앱입니다. UI와 모의 상태는 APK 내부에 포함됩니다. 일반 Android APK는 단일 기기 체험이며 로컬 서버와 자동 연결되지 않습니다.

`apk/ansim-platform-0.2.0-preview.apk`가 0.2.0 시험본입니다. 예전 파일명으로 남아 있는 APK와 과거 `build-reports/` 결과는 0.1.x 자료입니다. 새 결과는 `build-reports/v020/`에서 확인합니다. 빌드마다 시험 서명 키가 달라질 수 있으므로 기존 앱 업데이트 설치가 거부되면 이전 시험 앱 삭제가 필요합니다. 삭제 시 해당 기기의 체험 기록도 지워집니다.

CI는 테스트, Chrome UI 검사, Android 빌드와 서명 검사를 실행합니다. 자원 절약을 위해 0.2.0 CI는 에뮬레이터를 실행하지 않습니다. Pleos·실차 검증은 별도 작업입니다.

## 검증

```sh
npm test
python3 -m pip install playwright==1.57.0
python3 test/browser_smoke.py
```

브라우저 시험에는 Chrome 또는 Chromium이 필요합니다. 실제 루프백 HTTP를 사용해 두 창 간 동기화와 응답 유실 재시도를 확인합니다. `--content-fixture`는 네트워크 없는 화면 시험용이며 메모리 저장소를 쓰므로 실제 브라우저 재시작 검증과 구분합니다.

## 범위

데이터와 차량 신호는 가상입니다. 서버는 루프백 주소에만 열립니다. 시연용 역할 토큰은 실제 기관의 로그인이나 운영 인증을 대체하지 않습니다. 실제 개인정보를 입력하거나 서버를 인터넷에 공개하지 마세요.

기명·연락처가 포함된 접수양식, 인증키, 로컬 상태 파일은 저장소에서 제외합니다.
