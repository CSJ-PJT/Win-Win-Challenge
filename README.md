# 안심동행 플랫폼

어린이·어르신의 방문 준비와 도착, 직접 인계 확인을 연결하는 차량용 앱 프로토타입입니다.

## v0.4.0

- **안정적인 입력과 저장**: 방문자·보호자·담당자, 시설, 연락처, 승하차 장소, 방문 예정 일시, 도착지, 이동 도움, 글씨 크기
- **길안내**: Google 지도 주소 길안내(키 불필요), 좌표가 있을 때 카카오맵 길찾기, Android 주소 검색 및 직접 입력
- **역할별 화면**: 인계자는 이동·인계 버튼, 시설은 준비·인수 확인, 보호자는 조회, 어르신은 큰 버튼 도착 알림
- **확인 절차**: 도착 사실과 인계 완료를 구분하고 양측이 직접 확인해야만 인계를 완료

### 설치 없이 실행

`dist/handoff-demo.html`을 Chrome 등 브라우저에서 열거나 아래 명령으로 생성할 수 있습니다.

```sh
npm run bundle
npm test
```

로컬 서버에서 여러 브라우저 창으로 역할을 확인할 수 있습니다.

```sh
npm start
# http://127.0.0.1:8080
# /vehicle, /facility, /guardian, /visitor
```

Node.js 22 이상이 필요합니다. Android APK는 릴리스 첨부파일을 사용합니다.

### 사용 흐름

**인계자:** 방문 유형 선택 → 도착지 등록 → 방문 시작 → 지도 길안내 → 도착 확인 → 연결번호 → 직접 인계 확인.

**시설:** 맞이할 준비 확인 → 연결번호 입력 → 직접 인수 확인.

**보호자 조회:** 이동 및 인계 상황을 확인하지만 대신 승인하지 않습니다.

**쉬운 화면:** 본인 동의 → 도착 알림 → 담당자 확인.

### 지도·API

Google Maps URL은 별도 API 키 없이 주소로 길찾기를 열 수 있습니다. Android 주소 검색은 기기 Geocoder 지원에 따라 달라집니다. 로컬 서버의 장소 검색은 `KAKAO_REST_API_KEY`를 설정하면 작동합니다. 키가 없어도 주소 직접 입력과 외부 지도 길찾기를 사용할 수 있습니다. 비밀 키를 저장소·앱 설정에 넣지 않습니다.

자세한 검증 및 운영 전 확인 사항은 [QA040](docs/QA040.md)에 정리했습니다.
