# 안심동행 플랫폼

보호자·인계자·시설 담당자의 방문과 대면 인계를 연결합니다.

## 0.3.0

- 사용 유형별 화면: 인계자는 방문 진행, 보호자는 전체 상황 조회, 시설은 인수 업무만 표시
- 방문 전 설정: 이용자·보호자·시설·담당자·연락처·승하차 장소·예정 일시
- 저장한 도착지 재사용, Android 주소 검색, 카카오맵·Google 지도 연결
- 설정 변경 권한 검증과 방문 시작 후 정보 잠금
- 어르신용 큰 글씨, 도착 알림, 전화

## 실행

Node.js 22 이상에서 `npm start` 후 `http://127.0.0.1:8080`을 엽니다.
`/vehicle`, `/facility`, `/guardian`, `/visitor`는 역할별 화면입니다.
`npm test`는 도메인·HTTP·설정·지도 요청을 검사합니다.
`npm run bundle`은 설치 없이 열 수 있는 `dist/handoff-demo.html`을 생성합니다.

첫 화면에서 사용 유형을 선택하세요. 시설은 다른 사람의 대면 확인을 대신 처리할 수 없습니다.
한 기기에서 전체 과정을 확인하려면 하단 시연 도구에서 역할을 바꿉니다.

Android 앱의 주소 검색은 Android Geocoder를 사용합니다. 검색이 안 되는 기기는 직접 주소 입력 또는 지도 검색으로 이어집니다.
웹 서버의 주소 검색 API는 서버 환경변수 `KAKAO_REST_API_KEY` 설정 시 사용할 수 있습니다. 비밀 키를 앱 설정이나 소스에 넣지 마세요.

현재 배포물은 기관 계정 인증과 실차 연계가 완료된 운영 서비스가 아닙니다. 공개 서버 대신 loopback 전용 서버와 합성 데이터로 검증합니다.
업무 구분과 운영 전 확인 사항은 `docs/PRODUCT_REVIEW_030.md`, 검증 결과는 `build-reports/v030`에 있습니다.
