# 안심동행 플랫폼

어린이·어르신의 방문 준비, 도착 알림과 양측 인계 확인을 연결합니다.

## 0.4.2 — 주소 검색과 저장

**도착지 입력하기 → 주소 검색 → 실제 검색 결과 선택 → 상세주소 입력 → 저장**

카카오 우편번호 검색창에서 선택한 도로명·지번 주소와 우편번호를 가져옵니다. API 키 입력은 필요하지 않으며 인터넷 연결이 필요합니다. 검색 중이거나 검색창을 닫았을 때도 작성 중인 연락처·요청사항을 보존합니다. 저장한 도착지는 다음 방문에서 다시 사용합니다.

상단의 **인계자 · 보호자 · 시설 · 쉬운 화면** 탭으로 같은 방문을 이어서 시연합니다. 인계자 확인과 시설 인수 확인은 별개이며, 보호자 탭은 조회용입니다.

## PC 실행

Node.js 22 이상이 설치된 PC에서 압축을 풀고 **PC 실행.cmd**를 실행합니다. 소스 저장소에서는 먼저 `npm run bundle`을 실행합니다.

```sh
npm run bundle
node tools/serve-demo.cjs
# http://127.0.0.1:18420
```

이 서버는 이 PC의 루프백 주소에서만 열립니다. 종료하려면 실행 창에서 Ctrl+C를 누릅니다. **HTML을 직접 더블클릭해 file://로 열면 공식 주소 검색의 선택 결과를 돌려받을 수 없습니다.** PC 실행 파일 또는 위 명령을 사용합니다.

여러 브라우저 창에서 같은 방문 상태를 공유하는 서버는 별도로 실행합니다.

```sh
npm start
# http://127.0.0.1:8080
# /vehicle, /facility, /guardian, /visitor
```

## Android

릴리스의 `ansim-platform-0.4.2-preview.apk`를 설치합니다. 앱 내부 주소 검색창에서 선택한 주소가 방문 정보로 돌아옵니다. 외부 검색 화면에는 앱의 전화·차량 JavaScript 인터페이스를 노출하지 않습니다.

시험용 서명이 이전 버전과 다르면 기존 앱 삭제 후 설치해야 하며 기기의 이전 방문 기록은 지워집니다. 기관 계정 인증과 여러 휴대전화의 실시간 동기화를 제공하는 운영용 앱은 아닙니다.

## 지도

기본 지도는 카카오맵입니다. 주소만 있으면 **카카오맵에서 위치 보기**, 위도·경도가 있는 경우 **카카오맵 길찾기**로 연결합니다. 지도 화면에서 출발지와 경로를 선택할 수 있습니다. 설정에서 Google 지도로 바꿀 수도 있습니다.

주소 검색과 지도 열기는 다른 기능입니다. 우편번호 검색 결과를 위도·경도로 간주하지 않으며, 주소가 바뀌면 이전 주소의 좌표를 버립니다. 지도에 전달하는 값에는 이용자 이름·전화번호를 넣지 않습니다.

## 인계 시연

인계자 탭에서 방문 시작, 도착, 연결번호 발급, 직접 인계를 확인합니다. 시설 탭에서 연결번호 입력 후 직접 인수를 확인합니다. 한 기기 시연에서는 시연 도구의 **연결번호 입력하기**를 사용할 수 있습니다. 두 확인이 모두 저장돼야 인계 완료로 표시됩니다.

쉬운 화면은 본인 동의 후 도착 소식과 담당자 전화를 제공합니다. 도착 알림이나 담당자의 읽음만으로 대면 인계 완료가 되지는 않습니다.

## 검사

```sh
npm test
npm run bundle
python3 -m pip install playwright==1.57.0
python3 test/flow040.py
python3 test/role_tabs041.py
python3 test/address042_mock.py --fixture
python3 test/flow040_http.py
python3 test/address042_live.py
```

`address042_mock.py`는 오류·입력 보존을 재현하는 모의 SDK 시험입니다. `address042_live.py`는 실제 공식 검색 응답과 지도 연결을 검사합니다. Android의 `LiveAddressTest`는 설치한 release APK에서 실제 한국어 주소를 검색하고 선택해 저장합니다. 성공·실패 기록과 실행 화면은 해당 GitHub Actions 산출물에서 확인합니다.
