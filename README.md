# 도착완성: 안심동행

보호자·차량·시설 담당자를 연결하는 대면 인계 지원 앱.

## 개발 범위

- 어린이집·유치원 등하원, 어르신 주야간보호시설 방문 시나리오
- 지정 인수자 준비 확인, 정차 후 대면 인계, 양측 확인
- 담당자 부재·통신 장애·확인 불일치 시 완료 처리 방지
- 실제 개인정보 대신 합성 데이터로 시연

이 저장소는 공모전용 프로토타입입니다. 차량 도착이나 정차만으로 인계를 완료하지 않으며, 사람의 대면 확인을 대체하지 않습니다. Pleos SDK 연동 검증과 실제 차량 검증 여부를 구분하여 기록합니다.

실행 방법, 테스트 결과와 제출 자료는 구현과 검증 후 추가합니다.
